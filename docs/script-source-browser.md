# 脚本源分类浏览

源浏览器现在会显示已启用的脚本源。`getSources` 返回的子源会显示为分类；列表调用 `search({ keyword: '', sourceId, page })`，站内搜索使用第一个子源。点击视频时会把分类子源标识带入详情和播放页。

列表结果需要返回 `list`、`pageCount`。`pageCount` 控制加载下一页；站点只给出“下一页”链接也可以逐页浏览。可遍历范围取决于源站公开的列表，不承诺取得隐藏或已下架的视频。

## 更新已导入的 18J

已有脚本不会被内置版本覆盖。更新服务器代码、重新构建镜像并重建应用容器后：

1. 下载 `scripts/sources/18j-v2.import.json`。
2. 管理员打开 `/admin/source-scripts`，选择文件并导入。
3. 配置使用已有 key `j18`，更新同名脚本；如果之前使用了其他 key，请对应修改。
4. 刷新 `/source-browser`，选择「18J」，再选择「最新收录」或分类。

也可以复制 `scripts/sources/18j-v2.js` 到粘贴脚本框，源标识填写 `j18`，点击保存并启用。新安装没有同 key 脚本时，会自动播种内置 v2；已有管理员配置保持原样。

此脚本采用用户提供的 `/label/hot/by/time/` 和 `/t/{id}/` 分页规则。测试使用模拟 HTML，尚未联网验证站点分页覆盖范围。联想搜索不支持分页，只有第一页返回结果。
