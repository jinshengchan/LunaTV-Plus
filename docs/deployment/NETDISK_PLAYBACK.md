# 网盘搜索结果在线播放

首批接入夸克、UC：PanSou 负责搜索分享链接，MoonTV 读取分享目录，将选中的视频转存到已配置账号，再通过站内视频代理播放。其他网盘仍保留原有分享链接入口。

## 配置

1. 在管理后台的“网盘搜索配置”中配置 PanSou，并启用对应网盘的搜索。
2. 勾选“搜索结果在线播放（夸克、UC）”，在本站后台填写已登录网盘网页版的完整 Cookie。该授权通常包含多个 Cookie 字段，不能用 PanSou Token 代替。
3. 设置转存目录名称，默认 `MoonTV在线播放`，保存配置。目录在首次播放时自动创建，不需要手动查找目录 ID。
4. 搜索影视资源，点击“在线播放”，进入分享目录，选择视频或剧集。根目录只有一个视频时会自动准备播放。

账号为站点共用，仅管理员配置。普通用户只能读取启用状态；Cookie、分享访问令牌和带签名的网盘直链不会出现在普通用户接口响应中。需要使用支持后台配置的服务器存储模式，例如 Redis；localStorage 模式不能保存后台账号配置。

## 播放与维护

- 首次选择视频会转存该文件，占用账号容量。再次打开同一分享、同一目录下名称和大小一致的已转存文件时会复用它。系统不会自动删除账号文件；有容量限制时请自行维护专用目录。
- 分享可含多层目录，文件列表分页显示。当前页中的视频支持“下一集”和播完切换下一个视频；跨页需要翻页选择。
- 原画文件通过同源代理读取，支持 Range/206，拖动进度时重新请求有效下载链接。服务器需要足够的出站流量和带宽。
- 浏览器播放能力与 TVBox 不同：视频/音频编码必须受浏览器支持。此版本不提供 FFmpeg 转码，不保证所有 MKV、AVI 或特殊音轨可播放；优先选择常规 MP4。
- 播放会话有效期六小时，与当前登录用户及配置账号绑定。会话过期、更新账号 Cookie 或分享失效后，请重新选择搜索结果。
- Cookie 过期、风控、账号容量不足或会员限制都可能导致转存或获取下载链接失败，需要更新授权或选择可访问的资源。

服务器需能访问 `drive-pc.quark.cn`、`pc-api.uc.cn` 和网盘返回的实际视频 CDN；仅开放分享网页域名不足以播放。站内代理保留 SSRF 校验，每次跳转重新校验地址，只向对应网盘的 HTTPS 域名发送账号 Cookie。
